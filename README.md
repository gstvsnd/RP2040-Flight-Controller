# RP2040 Quadcopter Flight Controller (WIP)

**Experimental Prototype Project:** Embedded quadcopter flight-controller for a Raspberry Pi Pico (RP2040). Reading motion from an IMU, receiving radio commands from a controller, drives four motors with PWM to controll flight. **Status:** WIP (Work In Progress) & Unsafe.

## Project-Configuration

### Enviroment
  * VS Code "Visual Studio Code"
  * PlatformIO (VS Code Extension)
  * Arduino framework 
### Hardware
  * MCU: **Raspberry Pi Pico RP2040**
  * IMU: **MPU 6500/9250/9255**
  * Radio: **CRSF/ExpressLRS 2.4Ghz receiver & transmitter** (joysticks and switches)
  * Chassi: **Something 3D Printed**
  * Motors: **8520**
  * Battery: **680mah 95C LiPo**
  * Motorcontroller: **PWM Controlled Transistor Gates**
