# Hardware and Wiring Instructions

## Main Hardware BOM

### MCU
* 1x Raspberry Pi Pico (RP2040)

### IMU
* 1x MPU-6500 / MPU-9250 / MPU-9255

### Radio
* 1x CRSF / ExpressLRS 2.4 GHz receiver
* 1x CRSF / ExpressLRS 2.4 GHz transmitter (Radiomaster TX)

### Motors
* 4x 8520 brushed DC motors

### Motor Controls
* 4x AO3400A N-Channel MOSFETs for PWM
* 4x 100 ohm resistors (in series with PWM signals)
* 4.6 kohm pull-down resistors (x4)
* 4x SS34 flyback diodes

### Battery
* 1x 680 mAh 95C 1S LiPo

### Quadcopter Frame
* 1x 3D-printed PETG model
